# AI Observability
## Monitor, Log, and Trace Your AI Apps

Production-ready observability for AI applications.

**Live:** https://ai-observability.vercel.app

---

## Features

### Logging
- Structured logging
- Level-based filtering
- Context tracking

### Metrics
- Latency tracking
- Token usage
- Error rates
- P95 percentiles

### Tracing
- Request tracing
- Span tracking
- Performance analysis

---

## Getting Started

```bash
git clone https://github.com/cyber-lazer-mermicorn/ai-observability.git
cd ai-observability
npm install
cp .env.example .env.local
npm run dev
```
